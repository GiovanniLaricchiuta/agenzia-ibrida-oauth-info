Trattamento attuale

È stata acquisita la credenziale OAuth Desktop dell’applicazione, conservata cifrata nel vault locale Windows DPAPI. Sono conservati i metadati tecnici necessari a identificarne progetto, riferimento, versione e integrità. TAU e BST non sono ancora collegati tramite questo connettore: non sono stati acquisiti token utente o dati dei loro canali.

Dati e finalità del collegamento previsto

Il connettore utilizzerà YouTube API Services. Dopo il consenso separato del rispettivo account Google, lo scope youtube.readonly consentirà la lettura dell’identità del canale, dei metadati e dei contenuti disponibili necessari alle funzioni di consultazione dell’Agenzia. Le autorizzazioni, le credenziali e i dati saranno separati per cliente. Non sono richiesti accessi a Gmail o Drive, né permessi di pubblicazione o modifica. Le metriche avanzate di YouTube Analytics non sono incluse in questo collegamento.

Uso, accesso e condivisione

Il perimetro previsto limita l’uso dei dati alle funzioni autorizzate per il cliente. Non comprende vendita dei dati, impiego per pubblicità o trasferimento dei dati YouTube a provider di generazione AI. L’accesso di Giovanni ai dati del cliente dovrà essere esplicitato nel collegamento e autorizzato dall’utente. L’uso e il trasferimento delle informazioni ricevute dalle API Google devono rispettare la Google API Services User Data Policy, inclusi i requisiti Limited Use.

Conservazione e cancellazione

Attualmente la credenziale dell’applicazione è conservata localmente con versionamento; non è presente un archivio di dati YouTube acquisiti dal connettore. La procedura locale predisposta conserva i dati API soltanto in memoria per la consultazione, per un massimo di cinque minuti, senza scriverli su disco, log o backup. La chiusura della sessione e le richieste di cancellazione eliminano subito la cache; la revoca ne impedisce il riuso. Dopo riavvio non viene ripristinato alcun dato API. Il collegamento resta sospeso fino alla verifica degli agganci di questa procedura al connettore OAuth reale e alla cancellazione delle credenziali utente quando saranno acquisite. Attualmente non sono presenti credenziali utente YouTube.

Revoca e richieste sui dati

L’utente può revocare l’autorizzazione nelle connessioni del proprio account Google. La revoca dell’accesso e la cancellazione di eventuali copie locali sono operazioni distinte. Per richieste relative ai dati o all’accesso può contattare Giovanni Laricchiuta a laricchiutagiovanni2@gmail.com.

Pagine informative e servizi esterni

Le pagine informative sono statiche e utilizzano GitHub Pages, servizio di GitHub. Quando una pagina GitHub Pages viene visitata, GitHub registra e conserva l’indirizzo IP del visitatore per finalità di sicurezza, anche senza autenticazione. Il trattamento è descritto nella GitHub General Privacy Statement (https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Le nostre pagine non aggiungono moduli di raccolta dati, script di tracciamento o campi per credenziali. L’autenticazione e le chiamate API previste comportano comunicazioni con Google, secondo la Privacy Policy Google. L’utilizzo di YouTube è soggetto ai Termini di servizio YouTube.
